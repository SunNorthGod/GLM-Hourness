# 宣传视频（Remotion）

dsh-hourness 的介绍视频，全部用代码画（[Remotion](https://www.remotion.dev)，React 组件按帧渲染成 MP4），不录屏。独立的 Node 项目，有自己的依赖与检查，不进本仓库插件的构建、preflight 与 test（根目录 `eslint.config.js` 忽略本目录）。

现有两支，都讲编排层，GLM 通道只在片尾带一句：

- `Sample`：横版样片，24 秒，30 帧，四段（标题 4 秒、一句话许愿 8 秒、放行后自己往下做 8 秒、片尾 4 秒）。按 1920×1080 排版，用 `make-music.mjs` 的合成配乐。它是画面风格的基准。
- `Short`：竖版短视频，48 秒，30 帧，按 1080×1920 排版，用 `make-score.mjs` 的采样配乐，每一刀都落在配乐的小节线上（一小节 2 秒，共 24 小节）。开头是标题（名字和「DeepSeek Harness（DSH）的插件」），结尾是片尾卡。

渲染时整体缩放出 2K、4K，代码不用改。

## 用法

```bash
npm i
npm run music                    # 生成样片配乐 public/music/sample.wav
npm run score                    # 下载音色库（第一次），生成整片总谱 score.mid 并渲染成 score.wav
npm run dev                      # 先生成两份配乐，再开 Remotion Studio 预览
npm run render                   # 1920×1080，out/Sample.mp4
npm run render -- Sample 2k      # 2560×1440，out/Sample-2k.mp4
npm run render -- Sample 4k      # 3840×2160，out/Sample-4k.mp4
npm run render -- Short 2k       # 1440×2560，out/Short-2k.mp4
npm run lint                     # ESLint 与 tsc
```

## 竖版 `Short` 的结构

| 小节 | 秒 | 字幕 | 画面 | 配乐 |
| --- | --- | --- | --- | --- |
| 1–2 | 0–4 | 无（标题自带文字） | 第 1 拍名字 GLM-Hourness 淡入，第 3 拍（长音）出现「DeepSeek Harness（DSH）的插件」；第 2 小节在两行字下画出一条渐变细线，整组缓缓推近 | 开场：钢琴与慢弦乐，声音标志 E–D–G–C 与它的应答；第 2 小节里有一声轻的反向镲，引向钩子 |
| 3 | 4–6 | AI 说做完了／真做完了吗？ | 第 1 拍模型的气泡「✓ 全部完成」；第 2、3 拍各出一行红字：测试没过、改了不该碰的文件 | 钩子：同样两小节，加上鼓组与定音鼓 |
| 4–5 | 6–10 | 想挂机收菜／醒来全是返工（跨两小节） | 第 4 小节第 1 拍钟出现并从深夜转到早上，第 4 拍出现「待返工」的标签；第 5 小节每拍在标签下堆一行红色的改动 | 钩子后半，进主歌 |
| 6–7 | 10–14 | 聊得越久／越忘了要做什么（跨两小节） | 一段长对话，每拍长出一问一答并往上滚，第一句（目标）渐渐淡掉 | 主歌 |
| 8 | 14–16 | 它说测过了／你只能信 | 第 2 拍模型说「✓ 测过了」，第 3 拍证据一栏是空的 | 主歌末 |
| 9–10 | 16–20 | 模型改不了／能改的是它干活的环境（跨两小节） | 第 9 小节名字拆成 GLM、House、Harness，每拍一个；第 10 小节合回 GLM-Hourness，第 3 拍写 Harness 原意是驾驭 | 预副歌，弦乐渐强 |
| 11–14 | 20–28 | 你只在图上做决定／你问三句／它答四样（第 13–14 小节） | 项目图上出现目标；人问三句（第 12 小节）；主 Agent 答四样（第 13 小节，落在副歌第一拍）；第 14 小节人点头一次，目标下长出三块，两块已放行、一块设计中 | 预副歌的后两小节（反向镲、军鼓滚奏），第 13 小节进副歌 |
| 15–20 | 28–40 | 各领一件活／只能写划给它的文件／每件活都过独立审查／审查谁定深浅／主干只收检查过的提交／检查结果由系统记录 | 项目图：子 Agent 领活、独立审查、主干只收检查过的提交，越界的提交被挡下。第 3 小节的问题在第 20 小节得到回答 | 副歌 |
| 21–22 | 40–44 | 系统每周数给你看（跨两小节） | 周报卡：四行指标只有柱和趋势箭头，没有数字，标「示意」 | 尾声：F、借来的 Fm6、Cadd9，声音标志再响一次 |
| 23–24 | 44–48 | 无（片尾卡自带文字） | 名字、「DeepSeek Harness（DSH）的插件」、「GLM 通道是另一个包，两个包可以只装一个」，每拍进一行；第 24 小节整张卡淡出，不回到第 0 帧 | Cadd9 延留两小节，最后一个高音 C，渐弱至静 |

规则板与循环板不在竖版里，留给之后的横版 90 秒版。

定画面时照着核对的规矩：

- 开头是标题，结尾是片尾卡。第 0 帧不必是钩子，片尾不必接回第 0 帧，不要求循环。
- 痛点到转折（第 3–10 小节）一拍只进一样东西，不一下子砸下来。字幕落在小节线上，画面里的东西落在拍子上（一拍 15 帧）。
- 第 3 小节抛出的问题要在片尾卡之前回答（第 20 小节：检查结果由系统记录，模型说的不算）。
- 每 2 秒（一小节）换一次画面；字幕一小节一条，跨两小节的字幕下面画面每小节都变。标题与片尾卡自带文字，不另加字幕。关掉声音也看得懂。
- 字幕标题不超过 10 个字（88 px 一行放得下），细节放到副标题。
- 安全区：字幕与内容都在 x 45–945 这一列里（字幕以 x 495 居中），右侧留给点赞、评论按钮；画面下方约五分之一（y 1536 以下）留空，给平台的标题、按钮与进度条。

## 文件

- `src/Root.tsx`：登记 `Sample` 与 `Short` 两支。
- `src/short/`：竖版。`timeline.ts` 是小节与字幕表（每句字幕的出处写在注释里，`bars: 2` 的字幕跨两小节）以及项目图上每件事发生的帧；`Title.tsx` 第 1–2 小节的标题和第 23–24 小节的片尾卡（共用名字和「DeepSeek Harness（DSH）的插件」那一行，片尾卡多一行 GLM 通道的话并淡出）；`Claim.tsx` 第 3–5 小节的「✓ 全部完成」气泡和下面的红字；`Rework.tsx` 第 4–5 小节的钟和堆起来的返工；`Drift.tsx` 第 6–8 小节的长对话与「测过了」；`Name.tsx` 第 9–10 小节拆开又合上的名字；`Ask.tsx` 第 11–14 小节的三问四答与点头，叠在项目图上；`Graph.tsx` 项目图，按时刻求值，第 11–20 小节用它；`Report.tsx` 第 21–22 小节的周报卡；`Avatar.tsx` 对话里的圆形头像；`Caption.tsx` 字幕；`Short.tsx` 把各段排在小节线上并挂上配乐。
- `src/Sample.tsx`：四段的先后与时长，每段对齐配乐的小节（120 BPM，一小节 2 秒）。
- `src/scenes/`：每段一个组件。画面里的出现、打勾、进主干落在拍子上（一拍 15 帧）。
- `src/parts.tsx`：背景（深底、两团慢慢漂移的光晕、淡网格、颗粒、暗角）、淡入淡出、渐变字、毛玻璃卡片、描边胶囊、四行方案的加粗写法。
- `src/theme.ts`：配色（雾蓝到淡紫一组渐变作主色；进行中浅青、通过薄荷绿、强调杏色）、字体（英文 Segoe UI，中文微软雅黑）、缓动。
- `scripts/make-music.mjs`：配乐，从零合成，不用任何采样或第三方录音，所以没有本仓库以外的版权。风格是明亮的电子流行：七个微失谐的锯齿波叠成和弦并随底鼓抽吸，拨弦主旋律，低频贝斯，四拍底鼓与拍手，进副歌前的上升音效与落地的低频冲击。十二小节：前两小节铺垫，第 3–6 小节进副歌，第 7–10 小节最满（主旋律加高八度），最后两小节鼓退出、收在 Cadd9。和声 F–G｜Am–F–C–G ×2｜F–Cadd9。生成的 wav 不入库。
- `scripts/make-score.mjs`：整片的配乐。总谱在代码里写成 MIDI（`public/music/score.mid`，任何 MIDI 编辑器或宿主软件都能打开），再用真实乐器的采样渲染（`public/music/score.wav`，48 kHz）。24 小节、120 BPM、48 秒、C 大调：两小节开场（声音标志 E–D–G–C 和它的应答，钢琴和慢弦乐，第 2 小节里加一声轻的反向镲）、两小节钩子（同样的两小节，加鼓组与定音鼓）、四小节主歌、四小节预副歌、八小节副歌、两小节尾声、两小节结尾（Cadd9 延留，最后一个高音 C，淡出）。第 3–22 小节是加开场和结尾之前的 20 小节总谱，音符与力度一一相同；和声带副属和弦（E7/G#→Am7）、通往下属的 ii–V（Gm7 C7→Fmaj7）、借用的小调 iv（Fm6）与 V/ii（A7）。乐器：钢琴（伴奏与主旋律）、慢弦乐铺底、弦乐对位、指弹贝斯、钢片琴、拨弦、干净电吉他、定音鼓、反向镲与鼓组。渲染后过一道软削波，再按峰值归一到 −1 dBFS，整体响度（积分）约 −15 LUFS。采样渲染用 [SpessaSynth](https://github.com/spessasus/spessasynth_core)（Apache-2.0，npm 依赖）。
- `scripts/get-soundbank.mjs`：下载音色库 [GeneralUser GS](https://github.com/mrbumpy409/GeneralUser-GS) 及其许可到 `assets/`（不入库），按 GitHub 公布的 blob 编号校验。它的许可写明可以不受限制地用于自己的音乐创作，私用与商用都行。
- `scripts/render.mjs`：渲染，带 1080p、2k、4k 三档。先重新生成这一支的配乐（`Sample` 用 `make-music.mjs`，`Short` 先取音色库再跑 `make-score.mjs`），再调 Remotion；把 Chrome 的临时目录指到本目录的 `.tmp/`：本机上无头浏览器在系统临时目录里建不了缓存，渲染会在中途以 `write EOF` 退出。

## 内容的规矩

画面里的每一句都要在宪章（`docs/CHARTER.md`）或已放行的设计里找得到出处（`.agents/tasks/*/onepage.md` 与 `design.md`），不编没有定过的功能，不放没有来源的数字。第 3–8 小节的痛点（做完了没有、挂机后返工、对话越长越忘目标、只能信模型的话）是引子，不是对本产品的断言。标题和片尾卡上的「DeepSeek Harness（DSH）的插件」出自宪章 §1（让 GLM 住进 DeepSeek Harness），「GLM 通道是另一个包，两个包可以只装一个」出自宪章 §3 与 §5。周报卡只画柱和箭头，等有了真实数据再换成数。示例用的项目是会议室预约，与练习题（记账小工具）不相干。「主 Agent 自己从来不写文件」这句暂不上画面：PTC 工具预设下它还有一个已知缺口（M3 评审 S4-1），修好合入之后再放。对外发布之前，先复核 GLM 通道移植代码的许可与 GLM Coding Plan 的条款（项目图 `field-trial` 节点）。
