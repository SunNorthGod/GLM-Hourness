## 发现

1. F1（NIT）：两件事里「代价：」是行内标签。
   - 位置：onepage.md「要你定的」① 和 ② 的末句，各以「代价：」开头。
   - 问题：确认推荐的形状要的是「有真代价才加一句」，不是带标签的一行；`d-ask-three-gates` 取代的正是带标签的版式。这里标签在同一段里，不成独立一行，影响很小。
   - 改法：把「代价：大的审查派出去之后，会占着高峰的额度做完。」改为「代价是大的审查派出去之后，会占着高峰的额度做完。」；② 同样改为「代价是高峰按全价扣积分，跑一次要调用几十次。」

2. F2（NIT）：① 的理由句里混进了一个不是理由的分句，② 末尾的「它」指代不清。
   - 位置：onepage.md ① 「我建议做完，因为停在半截，已经做的部分会白费，要不要挪由主 Agent 在派活之前定」；② 「挪到 18 点以后会拖住它」。
   - 问题：① 里「要不要挪由主 Agent 在派活之前定」说的是谁来定，不是为什么建议做完，读成理由的第三项。② 的「它」可以指核对，也可以指改动并进主线。
   - 改法：① 拆成两句：「我建议做完，因为停在半截，已经做的部分会白费。要不要挪，由主 Agent 在派活之前定，这里只管已经派出去的。」② 改为「挪到 18 点以后会拖住改动并进主线」。

3. F3（NIT）：design.md 第 0.1 节「d-chat-not-cards」一行和第 20 节末段仍按四行版式描述放行稿的最后一件。
   - 位置：design.md 第 0.1 节表里 `d-chat-not-cards` 一行（「放行稿末尾的一件按这个写」）；第 20 节最后一段（「背景、推荐、疑问、不做四行」）。
   - 问题：页面按 `d-ask-three-gates` 和本次任务写成新形状，与这两处设计文字不一致。这是设计文字落后于人 2026-10-31 的决定，不是页面的错；本任务禁止改 design.md 的行为，作者没有改，这是对的。
   - 改法：由后续一次只改文字的设计修订，把这两处指向 `d-ask-three-gates`（页面的「要你定的」改用确认推荐等四种形状，四行版式作废）。不在本步做。

4. 页面其余各条与上一轮评审已核实的内容逐字相同（对照 `onepage-0.6.md` 的差异：第 1 条加了「预估的」，第 4 条把真账号核对的解释和「想放行」一句放进来，各条加粗去掉，场景里加了练习题的一句解释）。新增的几句我又核了：
