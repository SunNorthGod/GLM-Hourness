# M6 用量与高峰：给你看的一页

这一块管 GLM 的三件事：额度还剩多少、积分怎么算、高峰时怎么办。做完之后，你不用再去 BigModel 控制台查额度；高峰时练习题会先停下，说明 18 点以后再跑。完整设计在同目录的 `design.md`（0.4），这一页只讲你会碰到的部分。

## 你会看到什么

- 敲 `/glm-status` 或 `/hourness`：现在是不是高峰、到几点；5 小时额度和每周额度各用了多少、几点重置、照现在的速度什么时候用完。每一行都写着是按什么算出来的。
- 这些额度数字来自服务端，ZCode 等其他软件用掉的也算在内。
- `/hourness` 里的用量数字只算经 DSH 发出的请求，这一点会写明；10 月 29 日删掉的 806 条旧记录单独写一行，你看得出那段时间缺了数。
- GLM 登录失效时，`/glm-status` 那一段的第一行就写着，后面跟着 `/glm-login`。退出登录之后那里写「未登录」。
- 循环板上有一组「来自 GLM 通道包」的四条：高峰开始时提醒模型、看状态时读额度、额度快用完时告诉你、登录失效时提醒你。这四条只能看，不能改，也不能关。
- 规则页上的高峰档位（无影响、少做、不做）归规则板那一块，默认少做，你随时能改。

## 会自己发生的事

- 工作日 14 点到 18 点是高峰，GLM 按全价算积分，其余时间半价。每段高峰里，GLM 会话的第一步会收到一句提醒，提醒怎么说跟着你选的档位走：
  - 少做：可挪的重活（练习题、对照实验、大的审查）等到 18 点以后，由主 Agent 挪；必要的活和已经派出去的活照做。
  - 不做：GLM 的活等到 18 点，系统会叫它接着做。
  - 无影响，或者只装了 GLM 通道包：和今天的提醒一字不差，模型照常做。
  - 哪一档都不让模型换模型或换套餐。
- 默认少做：高峰里，在 Kiro 里跑的练习题和对照实验会停下，说明 18 点以后再跑，加 `--wait` 就自己等到 18 点。改了通道之后的真网核对照常跑。
- 选了不做：练习题和真网核对都先停下，18 点以后再跑（加 `--wait` 就自己等）。选了无影响：都照常跑。
- GLM 正在用的时候，至多每 15 分钟读一次额度；没人用 GLM 时一次都不读。
- 5 小时或每周额度用到 80%，或者照现在的速度一小时内会用完，主 Agent 在下一次回话里告诉你一句。每个额度周期只说一次。
- 登录被服务端拒绝时，主 Agent 告诉你运行 `/glm-login`。如果主 Agent 自己就跑在 GLM 上，它这时也回不了话，你会在 DSH 里直接看到请求失败。
- 读额度成没成功、额度用完、登录被拒、高峰提醒发了哪一档、练习题每次被放行还是被挡下，这几样数都由系统自己记下来，不靠模型报。

## 什么时候问你

不问。这一块没有要你定的事。上面那两句提醒（额度快用完、登录失效）是告诉你，不用回答。想改高峰档位时，去规则页或者用 `/rules peak` 改。

## 替你定了的方向

- 高峰提醒按档位换说法。少做和不做两档去掉「这只是告知、不要推迟工作」，换成那一档要模型做什么；无影响和只装 GLM 通道包时一字不改。提醒的原文归这一块，规则板只告诉它现在是哪一档（这是编排方定的分工，你可以推翻）。
- 少做时，已经派出去的活照做，挪不挪由主 Agent 在派之前定。没选让做到一半的子 agent 自己停下，因为它不知道自己的活能不能挪，停在半截会白做。
- 真网核对算「必要的活」，少做时照跑。没把它算重活，因为它挡着后面的合入，花的积分也少。
- 额度快用完的门槛是 80% 或一小时内用完。没选用完才说，因为那时已经来不及把活挪开。
- 只在 GLM 正在用的时候读额度。没选定时读，因为没人用时也会发请求，服务端对频繁查询限速。
- 读额度的请求照 ZCode 3.17.1 的样子发，失败了不重试。
- 写一行记录说明 10 月 29 日删过 806 条，删掉那个文件就撤销。
- 循环板上的 GLM 条目由 GLM 通道包交出来，编排层里不写 GLM 专属的东西。

## 交给别的模块的

- 少做档在 18 点高峰结束时，主 Agent 如果正闲着，由循环板上项目编排自己的一条叫醒它去做挪开的活；高峰里主 Agent 只剩被挡着的活时，不算它卡住、不来问你，由执行那一块停住、到点接着推。这一块只告诉它们几点开始、几点结束。
- 少做里的「同时只开一个 GLM 子 agent」、新手教程里讲高峰档位的那一句，归规则板和上手页。

## 放行

① 放行 M6 用量与高峰的设计

背景：这份设计照你定的**高峰模式**写好了，额度、按档位的提醒和练习题的排队都在里面，已经过了三轮评审，这是你允许的最后一轮修改。

推荐：评审通过后**直接开工**，按上面的方向做。

疑问：最没把握的是**少做时派出去的活照做**这一句，你想让高峰一到就把重活停下就说一声。

不做：不把**真网核对**也算重活，它挡着合入。

这样放行可以吗？
