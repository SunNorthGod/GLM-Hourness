# 面板说人话与新手引导：给你看的一页

设计 0.9，评审第 8 轮通过，没有挡路的问题。完整设计在同目录的 design.md。样子见 mockup-home.svg（首页）、mockup-modules.svg（框架与模块）、mockup-boards.svg（规则板与循环板）、mockup-onboarding.svg（上手说明）。

## 你打开面板，会看到什么

你在「读书会报名」这个项目里打开右侧栏的「项目图」，看到 mockup-home.svg 那一页：先是「做完 18 件，还剩 20 件」，再是「需要你」，再是谁在做哪件事、接下来的三件、上次看之后变了什么。

「需要你」里排着一件事，和主 Agent 在对话里问你的一样：一行题目，下面背景、推荐、疑问、不做各一行。没有选项，没有批准、拒绝按钮，只有一行「去主 Agent 的对话回话 ›」。你点它，跳到主 Agent 的对话，用自己的话回「可以」或「不行，因为……」。它记下之后，这件事从面板上消失。

## 对你有什么变化

1. 面板只看，不能点。改高峰档位也是跟主 Agent 说一句，或在输入框打 /rules peak。你说过「档位当然能选」，这一条最可能不合你意。
2. 项目按两层循环走时，首页多一行「6 个模块：1 个等你放行 · 2 个在开发 · 2 个设计中 · 1 个做完了」，点开是「框架与模块」页：框架、每块的状态、你定过的方向。放行之后新提的模块不进「需要你」，因为这时批不了，要等下次定框架，页上单列一行。这个仓库的图上还没有方向清单，所以这里暂时看不到。
3. 首页最下面是规则板和循环板，插件带来的条目只能看。你定的、带脚本的条目会写出脚本在哪、点开是原文、是不是你同意的那一版；改过一个字就不跑，要你在对话里再同意一次；还写明超时多久、超时或出错之后怎样。你同意的条目立刻生效，没有先试一阵的阶段。
4. GLM 高峰有三档：无影响、少做、不做，默认少做。三档都不影响主 Agent，它任何时候都照常回你，只管它派出去的子 agent 和重活。没装 GLM 包时这段不出现。
5. 第一次打开面板有一页上手说明，点「去首页」就跳过；GLM 另有三步上手：登录、选模型、发一句话。没有项目图的工作区：装了接管命令时，卡片上有「建一张项目图」，点了让主 Agent 先看一遍项目再接手；没装时写怎样建空目录。
