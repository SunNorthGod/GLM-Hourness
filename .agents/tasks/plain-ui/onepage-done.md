# 面板与新手引导：17 条「怎样算做完」的人话版

设计 1.3（第 8 条按第 9、10、11、12 轮评审改过）。这是 design.md 第 1.4 节那 17 条的人话说法，意思不变，只换了词。你对哪条想改，直接说「第几条改成……」就行，不用等下一轮。

## 面板（第 1 到 10 条，第 17 条）

1. 打开项目图，从上到下依次是：效果是、需要你、现在、怎么做、上次看之后。没有页签。窗口 1280×800、右侧栏默认宽度时，不用滚动就能看到「效果是」和「需要你」第一件的题目与背景。
2. 面板自己写的话里没有路线编号（例如 M3）、内部编号、「特性」「任务」这类类型名和英文状态词。标题是别人写的，照原样放进句子里。
3. 「怎么做」按先后排：前面还有没做完的事挡着的，排进「要等」，并写明等哪件。主 Agent 看到的「可以开工」和你在面板上看到的是同一个算法。
4. 「上次看之后」只列你离开面板之后的变化，你自己的操作不列。第一次打开列最近一天。点进去看细节再回来，列表不变。
5. 每一项都能「讲细点」展开、「说重点」收起，这两个按钮只改显示，不写任何东西。每一件的最下面有一份工作记录：类型、状态、编号、证据、历史、正文，你追问「凭什么」时看。
6. 「需要你」只列三种事：图上等你回话的题（背景、推荐、疑问、不做四行）；主 Agent 在对话里交给你、还没记下你回话的确认需求和放行方案；等你批准的提议。首页至多 3 件，第一件四行都显示，其余先显示题目和背景。每件下面一行，点了到主 Agent 的对话。已经放行的目标下面新提的模块不在这里，在「框架与模块」页。没有要你回话的事时，一行灰字写明。
7. 面板上没有批准、拒绝、选项、运行控制这类会改东西的按钮。要停一个任务或改规则，页上写明怎么做：跟主 Agent 说，或在输入框打一条命令。
8. 规则板和循环板，这一条最长，分几样：
   - 首页页脚有两块板的入口。插件带来的条目标明「只能看」，你能改的地方写一句怎么改。
   - 规则板有「会挡住动作的门」一组，列出合入前要跑的检查和必须全审的改动。
   - 你定的、带脚本的条目写明脚本放在哪，点开是原文，写明是不是你同意的那一版（改过一个字就不跑，要你再同意一次），写明超时多久、超时或出错之后放行还是拦下。
   - 写在代码里的规则从启用那天起就拦，没有先试一阵的阶段。每条写最近 7 天拦下几次，点开是最近 5 次拦下的记录（什么时候、拦下了什么、规则编号）。每条下面一行写撤下的办法，这一行由规则板给：能撤的写一句话或一条命令；今天还撤不了的（例如主 Agent 自己的几条规则，它们还没接上撤下的办法）写「这一条现在还不能一句话撤下」和原因，不给命令。这一组里没有「只记下，不挡」这类说法。
   - 你自己定的规则里，如果你选了「只记录、不拦」（先看看一条规矩会挡下什么），页面照原样写「只记下，不挡」，并写明这是你选的做法，不是试运行阶段。别的地方都不出现这句话。
   - 页面上没有读登录密钥文件的规则，也不记谁读过。
   - 带超时的条目，超时是「跑一次要多久」的 3 倍：第一次用写脚本的 agent 估的时间，跑过一次之后用最近几次里最慢的一次；不低于下限、不高于上限，这两个数每块板自己定（例如改完文件就跑的检查是 5 秒到 60 秒），面板照板给的写，自己不定数。主 Agent 可以为某一项把上限调高，页面写明调到几秒、什么时候、为什么，你说一句就能改回。超时的数后面写它从哪来，一共四种：agent 估的（写出估了几秒、乘 3）；跑过之后系统按最近几次里最慢一次的 3 倍定的；检查没写估计、数一开始就取上限，来源写「上限」；或者是设计里直接定的固定值（规则板和循环板今天还有一些这样的数；没写估计、先用设计里的缺省值的，也写这一种）。前两种算出来不足下限时，写明取了下限（例如「最慢的 1 秒算，3 倍是 3 秒，不足下限，取下限 5 秒」）；超过上限时，保持上限，并写明已告诉主 Agent。前两种点开能看到这个数留下的来历（每次怎么变的）、最近 5 次超时各自的限、实际用了多久、最后怎么处理的，还有最近 7 天超时几次（没有超时就写「最近没有超时」）；来源是「上限」或固定值的，这几样可以没有，没有就不显示，也不报缺。「上限」的数被第一次运行改成实测值之后，来源变成第二种，那时才有来历。数据缺了或对不上（例如没写取了下限，数却不是 3 倍），那一格写「没有记录」和原因，不留白。
   - 额度用完、自动推进停住时，首页「现在」多一行，说明约几点重置、之后自己接上。读不到这两样数据时，没有这一行。
9. agent 写给你看的标题、一句话理由、待决的背景和四行，违反写法规则时，先给警告，后来改成直接拒绝，并写明哪条规则、怎么改。你自己写的不查。
10. 「上次看之后」里，你在对话里的回话写成「你在对话里同意了……」「补充了……」「否掉了……」，确认需求和放行方案各一行。一块（模块或里程碑）做完写「这一块做完了」，整个目标做完写「做完了，整体审查的结论在它的节点页」，这两种各占一行，不并进「做完了……等 N 件」。
17. 项目按两层循环走、图上有你定过的方向清单时：首页每个分了模块的目标下多一行（例如「6 个模块：1 个等你放行 · 2 个在开发 · 2 个设计中 · 1 个做完了」），点开是「框架与模块」页，列框架、每个模块的状态、方向清单的每一条原文。一个模块等你放行时进「需要你」。放行之后新提的模块不进「需要你」，在这一页写成「等下一次定框架时一起定」。图上没有方向清单时，这些都不出现。

## 新手引导（第 11 到 16 条）

11. 只装项目编排、只装 GLM、两个都装，各自的引导都出现，且不提另一个插件的界面。
12. 第一次打开有项目图的工作区的右侧栏时，先看到上手页，分六块：一眼看懂、你要做的只有回话、让主 Agent 接手、规则板、循环板、去哪看进度。第 4 块在规则板装上时出现，装了 GLM 时讲高峰模式的三档（无影响、少做、不做，默认少做）和「三档都不影响主 Agent，它任何时候都照常回你」。第 6 块写明：每做完一块，主 Agent 用一两句告诉你；你不在时先攒着，回来一起给你；整个目标做完时再给一句，带整体审查的结论。装了 GLM 时，第 6 块再写：额度用完时推进会停住，主 Agent 会告诉你，额度重置后自己接上。点「去首页」之后不再自动出现，页脚「上手说明」能再打开。图上已有你自己操作记录的，不自动出现。没有项目图时，先显示没有图的说明。
13. 本机没有 GLM 上手记录时，开场画面和会话里都有「GLM · 上手」入口，点开是三步：登录、选模型、发一句话。读到已登录、点了「跳过」，或者开场的小按钮在 3 个不同会话里出现过，就记作完成，入口收起。设置页能重新打开。
14. 没有项目图的工作区：面板说明项目图是什么，并给出建图的路。装了接管命令时指向「在对话里发 /wish，主 Agent 先看一遍这个项目再接手」，开场画面的卡片带「建一张项目图」按钮；没装时写怎样建空目录，卡片没有按钮。这张卡片每个工作区只出现一次。
15. 项目编排的开场卡片，在上手页会自动出现的时候，底部多一行「第一次用？看看项目图怎么用」，点了打开右侧栏的项目图。开场画面上打不开右侧栏时，换成一句话：发出第一句话之后，在右侧栏打开「项目图」，上手说明会自己出现。
16. 引导里除了上手页的「去首页」点一次，没有别的需要点掉的东西，不弹窗，不发通知，不往对话里写字。

## 怎样改

第 8 条最长，我拿不准有没有说清，读到那里请多看一眼。想改哪条，说「第几条改成……」。你定下之后再改这 17 条要你出手，所以放行时一起看；其中第 6、9 条写的是旧问法的四行，面板换成新问法时要再请你改一次。
