# 视觉风格样张（三选一，或混搭）

人 2026-11-04：「视频背景配色主题之类的能不能改一下？现在AI味太浓了」。

## 现有画面里属于「AI 味」的元素

对照改前的 `video/src/theme.ts`、`video/src/parts.tsx` 与各场景逐项找出：

- 底：近黑的深蓝底 `#06070D`，上面三团缓慢漂移的径向光晕（靛蓝、淡紫、青），中心亮四周暗的淡网格，噪点颗粒，暗角。
- 渐变字：名字是白到淡蓝的银色渐变；House、Harness、「周报」、横版片尾第二行是靛蓝到淡紫的渐变；「检查过的提交」是薄荷绿到青的渐变。
- 毛玻璃卡片：半透明白色渐变底、发丝描边、`0 24px 70px` 的大投影、顶部内高光。所有气泡、项目图卡片、周报卡都是它。
- 发光：头像是双色渐变圆加紫色外发光；项目图的目标卡、进行中、已审查的卡都有彩色外发光；主干上的提交圆点发光。
- 呼吸灯：进行中的卡片描边和光晕按正弦波一明一暗。
- 其他渐变：人的气泡是靛蓝到淡紫的渐变底加紫色投影；标题下的线两头透明、中间淡紫；项目图连线从靛蓝渐变到淡紫；主干两端淡出。
- 字幕投影：字幕带一层黑色模糊投影。
- 配色：靛蓝、淡紫、青、薄荷绿、杏色、粉红，都是高亮度低饱和的「霓虹粉彩」。
- 动效：缓动是急起缓停的 `bezier(0.16, 1, 0.3, 1)`；徽标从 0.7 倍弹到原大，提交圆点从 0.4 倍弹出；字幕从 1.06 倍缩回；名字从 0.96 倍放大；横版标题字距从 24 收到 2；竖版标题整组推近 4%；每个元素出现时上浮 24 px。

三套主题都去掉了上面全部：没有渐变、光晕、毛玻璃、投影、颗粒、暗角、呼吸灯，也没有弹出、缩放、字距收拢和推镜。元素只淡入，纸面和白板的上浮距离减半（字幕下的元素从 24 px 减到 12 px），图纸风不上浮。进行中的卡片改成静止的虚线框。

## 纸面排版风 `paper/`

米白纸面上排好版的说明书：黑字，标题与字幕用宋体（思源宋体），正文用黑体（思源黑体），只有朱红一种强调色。

- 底：米白 `#F2EEE5` 平涂，四周一圈细框，像版心。
- 字：标题、字幕、名字用 Noto Serif SC；正文 Noto Sans SC；`main`、`dsh-hourness`、场景编号用 Cascadia Mono。
- 卡片：近白实底、黑色细线描边、3 px 小圆角。人的气泡是浅灰底无描边。头像是黑底白字（人）或白底黑圈（主 Agent、AI）。
- 颜色：朱红 `#C23B22` 只标三样：目标卡、方案里的加粗词、出错的东西（测试没过、待返工、没跑检查的提交）。House、Harness、「周报」也用朱红。其余全是黑与灰。
- 状态不靠颜色：进行中是灰色虚线框，审查通过是加粗黑框；「检查过的提交」是黑字加朱红下划线。
- 线：项目图连线改成黑色直角折线，标题下是一粗一细两道线。
- 取舍：状态全靠线的粗细与虚实，没有绿色和琥珀色，进行中和已通过在手机上一眼分得没有另外两套清楚。

## 工程图纸风 `blueprint/`

深灰图纸：细线网格，全片一种等宽字体，方框细线，颜色只标状态。

- 底：中性深灰 `#1F2226`，30 px 细网格加 150 px 粗网格，四周一圈图框。不偏蓝紫。
- 字：全片 Sarasa Mono SC（等距更纱黑体）。
- 卡片：比底稍亮的实底、浅灰细线描边、2 px 圆角。头像改成方块。
- 颜色只标状态：进行中琥珀 `#E0AC3E`（虚线框、进度条、子 Agent 标签），通过绿 `#6DBE6A`（审查 ✓、检查 ✓、主干上的提交），已放行蓝 `#6FA8DC`，出错红 `#E5604D`。目标卡与 House、Harness 是白色，方案里的加粗词是白字加下划线。
- 线：项目图连线是灰色直角折线；标题下是一道虚线，像图纸上的辅助线。
- 取舍：仍是暗底，离现在的观感最近；等宽中文在大字标题上略显宽松。

## 手绘白板风 `whiteboard/`

白板上拿马克笔画的：手写字、歪一点的框、带一点抖动的线和箭头，人的话写在黄色便签上。

- 底：白 `#FBFBF8` 平涂，无网格。
- 字：英文 Ink Free，中文楷体。
- 卡片：白底黑色粗笔描边，四个圆角大小不一。人的气泡是略微歪着的黄色便签。头像是手画的圈。
- 颜色是四支马克笔：黑、蓝 `#1F5FBF`（目标、强调词、House、Harness、已放行）、绿 `#2E8B47`（审查 ✓、检查 ✓）、红 `#D0342C`（出错），另加橙 `#D9730D` 标进行中。
- 线：项目图连线是带抖动的黑色曲线，末端有开口箭头；标题下是一笔蓝色马克线；钟面同样带抖动。
- 取舍：三套里最不像机器做的；楷体通篇读起来偏课堂板书，粗楷体的大字标题较重。

## 代码怎么组织的

- 主题层在 `video/src/theme/`：`tokens.ts` 定义一套主题要给出的全部样式（颜色、字体、底、卡片、徽标、气泡、头像、连线、主干、光晕、钟、缓动与动效开关），`current.tsx` 是现在的样子，`paper.tsx`、`blueprint.tsx`、`whiteboard.tsx` 是三套候选，`index.tsx` 登记主题并通过 React context 提供给各场景。
- 两支片都接受 `theme` 属性，默认 `current`；渲染时可用 `--props='{"theme":"paper"}'` 选主题。
- 场景里不再写死颜色、字体、渐变和光晕，只向主题要；布局与时间仍在场景里。
- 抽层前后，`current` 主题在两支片 40 个帧上与改前代码逐字节相同（Short 28 帧、Sample 12 帧，PNG 哈希一致）。
- 字体都取本机已装的字体（思源宋体、思源黑体、Cascadia Mono、等距更纱黑体、Ink Free、楷体），和现在用 Segoe UI、微软雅黑一样。定稿后若要在别的机器上渲染，需另定是否随项目带字体文件。
