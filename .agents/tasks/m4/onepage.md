# M4：补拦截、补检查，给你看的一页

这一块在项目图上叫 M4，给系统补三样东西：agent 做错事时的拦截与记录，agent 要写工作区以外的文件时先问你，agent 改完代码后自动跑检查。
它分七个小任务：拦截的试运行与统计、四条新规则、写工作区以外文件的申请、改完就跑的检查、环境与草稿区、跳过检查的注释计数、清理抓取脚本。
完整设计在同目录的 `design.md`（0.5），怎样算做完的草稿在它的 1.2 节。设计评审到第 5 轮通过，各轮挡路的问题是 8、2、6、4、0 条，剩 9 条不挡路的小问题，开工时顺手处理。这一页只讲你会碰到的部分。

## 你会看到什么

- agent 要写工作区以外的文件时，系统先拦下它，拒绝信息里带一个申请编号。agent 拿编号向你申请，申请是回复末尾的一段话：一行题目，背景、推荐、疑问、不做四行，再一句问话。
- 路径、文件在不在、多大、旧内容会不会先备份，都是系统自己查了写的。agent 只写三句话（为什么要写、能不能撤回、试过什么别的办法），放在「附」里，加引号标明是它说的。
- 例子：agent 要把今天新添的曲目追加到音乐播放器读的歌单文件，你会读到：

```text
要改工作区外的文件：C:\Users\me\music\playlist.m3u

背景：agent 要**改工作区外的文件**，系统先拦下了

推荐：**放行这一次**，旧内容先备份，改坏了能找回

疑问：这个文件若**不归这件活管**，就不该放行

不做：**不放行**，文件不动，agent 换在工作区里做

附：
- 文件现在：已存在，1,386 字节，10-30 09:12 改过
- agent 说的目的：「把今天新添的曲目追加到歌单」
- agent 说还会碰到：「不碰别的文件」
- agent 试过的替代：「写在工作区里，但播放器只读它自己的目录」

放行这一次，可以吗？（回「可以」才算数）
```

- 你回「可以」，同一个调用在 30 分钟内放行一次。用之前系统重新核对文件，没变才写，写之前先备份旧内容。回别的话都不放行；回得含糊时，系统给 agent 一句确认句让它再问，连续三次读不懂就作罢。
- 你一直不回，2 小时后申请作废，并叫醒 agent。DSH 或插件重启后申请也作废，agent 重新申请。
- 同一件活做完后又被重新打开，到第 3 次时，主 Agent 在下一批问题里问你「先停下查原因，可以吗？」。四行写好，附前两次重开的时间和理由。
- agent 改完文件，下一步开头多一小段检查结果：每个检查报几处问题，最多列 5 条，带文件和行号，落在改动行上的排前面，完整输出写在日志里。没有问题就不出声。
- 每个会话开头，agent 收到一段环境提醒：项目里有哪些工具、怎么用，改完哪些文件会自动检查，临时脚本放哪。
- 晨报多几行：拦下几次，拦下之后下一步走对了几次；申请几次，放行几次，没回几次；代码里跳过检查的注释现有多少处，比上期多了或少了几处。
- 循环板上多两条只能看的条目：「改完文件就跑检查」和「同一件活第三次返工之前：停下问你」，各带它自己的几条规矩。规则板「写在代码里的规则」里多出新加的几条，旁边写「只记下，不挡」。
- 设置页多一行 env（环境），默认关着，验证过才打开。

## 会自己发生的事

- 新加的四条规则先试运行，只记录、不拦：读登录密钥文件；新写的跳过检查的注释没有理由，也没挂图上的节点；改检查工具的配置或基线文件；在草稿区以外新建一次性脚本。
- 每拦下一次，系统记下 agent 的下一步：走对了、原样重试、做了别的、没有下一步。量的是拦了之后改对没有。
- 记录由 agent 标「该拦、误伤、说不准」，带你原话的标注算你的。一条规则要转成真拦，需要带标注的会拦样本至少 20 条、试运行至少 14 天、误伤 0 条。数字够了，M7 的周报才把它提给你，转不转你定。
- 用今天的规则重看你本机的历史会话，当天就有样本。你说过「不介意」，所以只读工具名、命令文本和路径，外加当时用的模型、工作目录、这次调用有没有报错。聊天内容和任何工具输出都不读。结果留在项目的 `.llm/`，只有去掉路径的个别样本进仓库的测试语料。
- 检查分两种。自带的检查器取自你批准过的项目图环境分支里工具节点上的检查行，改完文件后在 agent 的下一步之前跑，直接起程序、不经 shell，每个最多 60 秒，一步最多等 20 秒。你自己加的检查是循环板上你的普通条目，由循环板跑，你同意时在对话里看到命令原文。循环板没装上时，自带的检查器不跑，页上写明。
- 一个检查跑不起来或输出读不懂，连续 3 次后这个会话不再跑它。超时不算这 3 次，下一次改动照常再跑。
- 临时脚本放 `.llm/scratch/`，不进 git。项目没有忽略 `.llm/` 时，系统在本机的 `.git/info/exclude` 加一行。
- 删掉 `.llm/docs/` 下三个一次性抓取脚本和 `__pycache__`，地址和重新抓取的办法先抄进文档，抓下来的文件留着。
- 装了 M7 时，派出去写文件的 agent（worker）写到项目里、但出了它自己工作树的文件，由 M7 按自己的办法处理（worker 请主 Agent 放宽它的写入范围），不来问你。写到项目以外，worker 把编号交给主 Agent，主 Agent 问你，你回「可以」后 worker 原样再写一次。申请开着时，主 Agent 的自动推进停下等你，你回了才接着走。
- 高峰不影响这一块。主 Agent 在任何一档都照常回话，申请、第三次返工的提问、改完就跑的检查也都照常。
- 违规记录、标注、回放结果、备份和检查日志都存在这个项目的 `.llm/` 下，不进 git，用户目录里什么都不存。
- 主 Agent 自己做完、自己审、自己合进主干。改到拦截和权限的每一步都全审，由更强的模型逐条对着看。

## 什么时候问你

- 现在：这一页能不能开工，七个小任务怎样算做完（见末尾）。
- 一条规则达到转成真拦的数字时，在周报里问。
- agent 每次要写工作区以外的文件时。申请单独放在回复的最后，所以那条回复里只有它一件。
- 同一件活要修第 3 次时。
- 你要在循环板上加自己的检查，或加一个带检查的工具节点时。主 Agent 在对话里问一次，命令原文附在四行之后。
- 别的事主 Agent 自己定，攒着在下一批告诉你，一次至多三件。

## 替你定了的方向

- 放行只认你在 DSH 输入框里打的下一句话，而且这句话要紧跟在申请原文后面。agent 写的任何话都不算。没选信 agent 的转述：想要这次写入的正是它。
- 回话要整句是「可以」「行」「同意」这类词才算同意，「可以吗」「可以，顺便把 b 也改了」都不算。没选按意思判断：那等于模型自己批。
- 放行只管同一个调用一次，30 分钟内有效，重启就作废。没选把放行存在磁盘上：多一个要守的文件，重启又少见。
- 读登录密钥文件只记录，永远不拦。没选转成真拦：你排查登录时要让 agent 读，拦下是误伤。
- 自带的检查器随你批准那个工具节点生效，命令直接起程序，环境里没有登录密钥。想要和你自己加的条目一样硬的防线，就把检查行写成不带适用范围，再加一条条目引用它，这样 M4 不会自己跑。没选把所有检查都做成你加的条目：自带的要在 agent 的下一步之前跑完，循环板的收件箱默认要等 30 秒才合并处理，赶不上。
- 第三次返工只问你，不拦。没选直接拦下：那要另一条规则，也要先试运行。
- 转成真拦的数字 20 条、14 天、0 误伤，是 agent 定的，你可以改。没选按比例（比如 95%）：样本少时比例不稳。
- 回放不读出错结果的文字。没选读开头几个字符：shell 的输出里可能有文件内容和密钥，超出你说的「不介意」。
- 申请不上项目图，只留在内存、违规记录和会话日志里。没选上图：授权用不着它，多一种失败。
- 抓取脚本删除，不转成正式脚本。没选转正：本仓库不用 Python，网页工具现成。

## 你之前定的，照着做

- 问你的事都在对话里，一个方案四行，不出选择卡、不列选项。
- 项目的东西存在项目里：定义进仓库，运行记录进 `.llm/`。用户目录只留登录和人设。
- git 交给主 Agent，会丢东西的 git 命令由 M3 先存一份能恢复的。这一块的规则不判 git。
- 对所有模型和渠道生效，不装 GLM 通道包也一样。
- 每条新的代码规则先试运行再转真拦；你自己在板上加的条目不用试运行，你看过原文同意就生效。

## 交给别的块的

- 循环板：跑你自己加的检查，页面上列出这一块自带的检查器和那两条只能看的条目。
- 规则板：把这一块登记的代码规则列在「写在代码里的规则」里。违规记录里规则板写的「只记录」「晚到的拦下」两种标记，由这一块的读法认。
- M7：写入范围的检查向这一块要申请编号、查放行。申请开着时停住自动推进，你回了或到点作废时恢复。周报提议转成真拦时用这里的数字，合入前查草稿区是空的。
- M3：git 存档那一步的拦截也进「拦下之后走对没有」的统计。有申请开着时，主 Agent 不再同时出示别的提议。
- 面板：「需要你」里列出开着的申请，下面一行「去主 Agent 的对话回话 ›」，不放按钮。
- 指标流水：这一块交拦截、跟进、申请、放行的事件，只带规则、结果、来源和会话，不带命令和路径。
- 以上各块的设计都已放行。按你定的「搬进 DSH 自己开发自己之前，不往已放行的设计里塞新要求」，这些请求等搬进去之后再处理，这一块不要求它们现在改任何东西。

## 放行

推荐：**照这页开工**，怎样算做完先照草稿写进项目图。

疑问：若你**不想每次回「可以」**，申请那一条要重写。

不做：**逐条读完再定**，共 34 条约 5,800 字。
