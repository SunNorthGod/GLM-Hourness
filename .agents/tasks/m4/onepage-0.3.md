# 拦截规则补齐这批活：开工前的一页

这批活在项目图上叫 M4。它给系统补两样：agent 做错事时的拦截与记录，和改完代码自动跑检查。下面是做完之后你会碰到的事。

## 你会看到什么

- agent 要改**工作区外的文件**时，回复末尾有一段四行的申请
- 申请里写清**哪个文件、写什么**、旧内容会不会先备份
- 你回「**可以**」就放行**这一次**，回别的都不放行
- 同一件活**要修第 3 次**时，主 Agent 先问你要不要停下查原因
- 晨报多几行：**拦了几次**、拦下之后**改对了几次**
- 晨报还写：申请放行几次、代码里**跳过检查的注释**有多少处
- 设置页多一行「**开发环境**」，验证过之后才打开

## 它自己会做的

- agent 每次改完代码，**自动跑检查**，当场把问题告诉它
- 新加的四条规则**先只记录、不拦**，攒够样本再说
- 用今天的规则**重看你本机的历史会话**，只看命令和路径
- 每个会话开头告诉 agent **项目里有哪些工具**、临时脚本放哪
- 临时脚本放 `.llm/scratch/`，**不进 git**
- 删掉 `.llm/docs/` 下**三个一次性抓取脚本**，地址先抄进文档
- 主 Agent **自己做完、自己审、自己合进主干**
- 改到拦截规则的每一步都**全审**：更强的模型逐条对着看

## 什么时候问你

- 现在：**这页能不能开工**，怎样算做完先不先照草稿
- 某条新规则**攒够样本**、要从只记录改成真拦时
- 同一件活**要修第 3 次**时
- 项目**要加新的检查工具**时
- 用的时候：agent 每次要**改工作区外的文件**时
- 别的事**主 Agent 自己定**，攒着下一批告诉你，一次至多三件

## 替你定了的方向

- 放行**只认你在对话框里打的话**，agent 自己写的不算
- 你回得**含糊就不放行**，系统给一句确认句再问你
- **读登录密钥文件只记录**，永远不拦，排查登录时要用
- **电脑或 DSH 重启**之后，没用完的放行作废，要再申请

## 你之前定的，照着做

- 重看历史会话：你说「**不介意**」，只看命令和路径，不看聊天内容
- 只有个别样本**去掉路径**后进仓库，其余留在本机
- **git 交给主 Agent**，会丢东西的 git 命令先存一份能恢复的
- 问你的事**都在对话里**，不出选择题
