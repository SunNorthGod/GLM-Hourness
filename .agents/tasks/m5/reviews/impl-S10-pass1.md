The fold keeps only `origin.{actor, session, agent, relay}` and `mergedFrom`, so the richer lines need journal joins the fold does not keep — disclosed in progress.md; plain-ui's page can restore them.
4. Evidence is plain text; the design's clickable commit/node ids are deferred to plain-ui (disclosed under "Left for later steps").
5. The footer `div.glmg-foot` renders whenever any board is registered, including when none is available (rows off), leaving an empty strip with a border-top and no 「经验」 text. Acceptance item 4 (页脚不显示「经验」) holds; the strip is cosmetic until plain-ui's real footer replaces it.

7. The 15 s poll runs while the page is subscribed (mounted), not strictly while visible; the page is only mounted while its board page is open on the second layer, and the body is inert under it, so the two coincide in practice.
8. The board page and the temporary footer live in `ui/src/graph/Panel.tsx`, which the static check does not scan — correct for now (the ban is per plain-ui 0.7 §1.4 check 7 scoped to `ui/src/lessons/`), but plain-ui's own graph-wide check will own that directory later.
