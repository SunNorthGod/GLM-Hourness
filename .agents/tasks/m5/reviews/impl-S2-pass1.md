Design 3.1 words the rule as same name in both scopes, and `judgeStore` only sees one file, so nothing warns the writer. S4's `memory_query` `shadows` field makes the case visible; no change needed here.
3. `takeLock` waits out EPERM only. The stress loop in the commit message saw EPERM alone, so that is what is covered; if EBUSY or EACCES show up on Windows later, they belong in the same function.
